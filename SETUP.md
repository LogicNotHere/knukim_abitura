# Setup: задачи через git, вопросы агента идут владельцу

## Для исполнителя (один раз, ~2 минуты)

1. Клонировать репозиторий и открыть его в Claude Code.
2. Убедиться, что `git push` работает без пароля (SSH-ключ или `gh auth login`).
3. В Claude Code выбрать режим разрешений **Auto** (или Accept edits), чтобы агент не спрашивал разрешение на каждую команду.

**Дальше каждый раз:** написать в чат `чекни апдейт` (или `/go`). Всё.

Агент сам заберёт задачу, сделает её и запушит. Если у него появится вопрос, вопрос уйдёт владельцу через git, а агент дождётся ответа. Исполнителю отвечать ничего не нужно.

## Для владельца

- **Поставить задачу:** отредактировать `TASK.md`, сделать push и написать исполнителю «чекни апдейт».
- **Ответить на вопрос:** в репо появится коммит `❓ ...` и файл `questions/Q-....md`. Открой его на GitHub (✏️ Edit), впиши ответ под `## ОТВЕТ` (номер варианта или текст) и нажми Commit. Агент подхватит ответ в течение ~30 секунд и продолжит работу.
- **Результат** лежит в `REPORT.md` и в коммитах.

### Уведомление на телефон о вопросе (по желанию)

Поставь приложение ntfy, подпишись на свою придуманную тему (например `vitalii-agent-7f3k`) и добавь в `.claude/settings.json`:

```json
"env": { "NTFY_TOPIC": "vitalii-agent-7f3k" }
```

## Как это устроено

`.claude/settings.json` вешает хук на инструмент `AskUserQuestion`. Хук `.claude/hooks/ask_via_git.py` не показывает вопрос исполнителю. Вместо этого он коммитит вопрос в `questions/`, пушит и каждые 30 секунд проверяет, появился ли ответ. Ответ он передаёт агенту.

- Если ответа нет ~55 минут, агент продолжает независимую часть работы и проверяет ответ позже.
- Если запушить не получилось, вопрос показывается исполнителю как обычно (запасной вариант).

Настройки: `ASK_POLL_SECONDS` (по умолчанию 30) и `ASK_WAIT_SECONDS` (по умолчанию 3300). Нужен `python3`: на macOS и Linux он есть, на Windows замени в settings.json `python3` на `python`.
