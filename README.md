# Демо-сайт для абитуриентов КНУКіМ

## Для исполнителя

### Один раз (~5 минут). Это делаешь ты сам, не агент

**Шаг 1. Прими приглашение.**
Открой https://github.com/notifications (или письмо от GitHub) и нажми **Accept invitation** для репозитория `knukim_abitura`.

**Шаг 2. Скачай репозиторий и запусти Claude в его папке.**
Открой Терминал и вставь одну строку:

```bash
git clone git@github.com:LogicNotHere/knukim_abitura.git && cd knukim_abitura && claude "чекни апдейт"
```

Если Claude у тебя в приложении, а не в терминале:
1. В Терминале выполни только `git clone git@github.com:LogicNotHere/knukim_abitura.git`
2. В приложении Claude открой **новую** сессию и выбери папку `knukim_abitura`.
3. Напиши там `чекни апдейт`.

> ⚠️ Важно: Claude нужно запускать **именно в папке `knukim_abitura`**. Если просто кинуть ссылку агенту в другой сессии, вопросы агента будут приходить тебе, а не владельцу.

**Шаг 3. Если на шаге 2 ошибка `Permission denied (publickey)`.**
Значит, git не залогинен в GitHub. Выполни по очереди:

```bash
brew install gh
```
```bash
gh auth login
```
(выбери GitHub.com → HTTPS → Login with a web browser), потом:
```bash
git clone https://github.com/LogicNotHere/knukim_abitura.git && cd knukim_abitura && claude "чекни апдейт"
```

**Шаг 4. Включи режим Auto.**
В Claude Code выбери режим разрешений **Auto** (в приложении это переключатель режима возле поля ввода; в терминале — `Shift+Tab`, пока не появится auto). Тогда агент не будет спрашивать разрешение на каждую команду.

**Шаг 5 (по желанию). Tailscale.**
Добавь владельца в свою сеть Tailscale, чтобы он мог открыть демо по ссылке.

### Дальше каждый раз

- Владелец пишет «апдейт», а ты пишешь Claude в папке `knukim_abitura`: **`чекни апдейт`**. Всё.
- Вопросы агента автоматически уходят владельцу через git. Тебе отвечать не нужно, ты их даже не увидишь.
- Пока агент работает, не закрывай окно Claude и не выключай компьютер.

Подробности в [SETUP.md](SETUP.md).

## О сайте

Адаптивне демо для вступників КНУКіМ.
Стек: Next.js App Router, React, TypeScript та CSS Modules.
Потрібен Node.js 20.9 або новіший.

### Запуск

```bash
npm install
npm run dev
```

Відкрийте http://localhost:3000.
Сервер слухає `0.0.0.0`, тому його можна відкрити через Tailscale на порті `3000`.

### Перевірки та production-збірка

```bash
npm run typecheck
npm test
npm run build
npm start
```

`npm test` перевіряє перетин фільтрів каталогу та умови підбору програм.
`npm start` запускає готову production-збірку на порті `3000`.

### Сторінки

- `/` — головна.
- `/admissions` — вступ 2027.
- `/faculties` — каталог факультетів із пошуком та фільтрами.
- `/faculty/film` — приклад факультету.
- `/department/directing` — приклад кафедри.
- `/program/film-directing` — приклад освітньої програми.
- `/courses` — підготовчі курси.
- `/course/cinema-start` — курс із демо-реєстрацією.
- `/matcher` — підбір програми за трьома кроками.
- `/results` — результати підбору.
- `/events` — події та їхні описи.
- `/contacts` — контакти та локальна форма запитання.

Інші факультети, кафедри, програми та курси мають власні адреси.
Їхні `id` зберігаються у `data/demo-data.json`.

### Структура

- `app/` — маршрути Next.js та спільний layout.
- `components/` — картки, сторінки, фільтри, форми та CSS Modules.
- `lib/` — типи, доступ до даних та чисті функції фільтрів.
- `data/demo-data.json` — тестові факультети, кафедри, програми, курси, події та контакти.
- `public/images/` — локальні фото та `sources.json` із джерелами.
- `tests/` — регресійні перевірки каталогу та підбору.
- `demo/desktop.png` і `demo/mobile.png` — знімки головної сторінки.

Усі ціни, дати, імена, структури та контакти — демонстраційні приклади.
Форми перевіряють поля в браузері.
Вони не надсилають та не зберігають введені значення.
Перезавантаження сторінки скидає відповіді підбору.
Сайт не має backend, авторизації, оплати або справжньої реєстрації.

Офіційний сайт університету: https://knukim.edu.ua/.
Повний звіт: [REPORT.md](REPORT.md).

### GitQ

Claude Code та Codex використовують спільний GitQ на цьому Mac.
Запускайте `bin/gitq` з основного репозиторію.
Потрібні `/opt/homebrew/bin/python3.12` та `/Users/vlad/.agents/tools/gitq/`.

```bash
bin/gitq doctor
bin/gitq status --repo knukim
bin/gitq policy --repo knukim
```

Псевдоніми `knukim` та `knukim-abitura` вказують на цей репозиторій.
Приватні правила GitQ закріплюють `q2012Second` для push.
GitQ зберігає активний обліковий запис GitHub без змін.
