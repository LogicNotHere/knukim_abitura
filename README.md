# Демо-сайт для абитуриентов КНУКіМ

## Для исполнителя: что делать (одна команда)

```bash
git clone git@github.com:LogicNotHere/knukim_abitura.git && cd knukim_abitura && claude "чекни апдейт"
```

Дальше, когда владелец пишет «апдейт», напиши в этой папке Claude: **`чекни апдейт`**. Больше ничего делать не нужно.

- Вопросы агента автоматически уходят владельцу через git. Тебе отвечать не нужно.
- Нужно один раз: `git push` работает без пароля, а в Claude Code выбран режим **Auto**.
- Подробности в [SETUP.md](SETUP.md).

## Для владельца

- ТЗ лежит в [TASK.md](TASK.md), отчёт агента в [REPORT.md](REPORT.md).
- Вопросы агента появляются в `questions/`. Ответ пиши под `## ОТВЕТ` и коммить.
