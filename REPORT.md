# Звіт про демо для вступників КНУКіМ

Демо працює як самостійний застосунок Next.js App Router із TypeScript та CSS Modules.
Код і локальні фото розміщені в корені цього репозиторію.
Для запуску не потрібні інші локальні проєкти або агентські інструменти.

## Запуск і перегляд

1. Встановіть Node.js 20.9 або новіший.
2. Виконайте `npm install`.
3. Виконайте `npm run dev`.
4. Відкрийте http://localhost:3000.

Команда запускає сервер із `-H 0.0.0.0`.
Це дозволяє перегляд через Tailscale на порті `3000`.
Публічний хостинг або тунель не потрібні.

Для production-режиму виконайте `npm run build`, потім `npm start`.

Адреса в наявній tailnet: http://macbook-pro.tailb2f9c2.ts.net:3000.
Перевірка з цього Mac повернула `HTTP 200`.
Для перегляду потрібен доступ до цієї tailnet.
Віддалений перегляд власником окремо не перевіряли.

## Що реалізовано

- Головна зі збереженим дизайном: біла основа, чорні блоки, фіолетові та салатові акценти.
- Вступ 2027 із рівнями освіти, схемою кроків, прикладами дат, документами, вартістю та FAQ.
- Каталог факультетів із пошуком, інтересами, рівнем, творчим конкурсом та формою навчання.
- Окремі сторінки факультетів, кафедр та освітніх програм.
- Каталог курсів із фільтрами напряму та формату.
- Окремі сторінки курсів із локальною демо-реєстрацією.
- Підбір програми за інтересами, заняттями, рівнем, формою, конкурсом та бюджетом.
- Результати з поясненнями збігів, порожнім станом, зміною та скиданням відповідей.
- Події з фільтрами та модальними описами.
- Контакти за категоріями, умовна карта та локальна форма запитання.
- Мобільне меню, стани фокуса, закриття модальних вікон клавішею Escape.
- Прямі адреси сторінок і стандартна історія браузера.

Дані містять 8 факультетів, 10 кафедр, 15 програм, 5 курсів, 6 подій та 6 вигаданих викладачів.
Основні сутності та контакти зберігаються окремо від компонентів у `data/demo-data.json`.
Усі фото локальні; джерела наведені у `public/images/sources.json`.

## Маршрути для показу

Основний шлях:

`/` → `/faculties` → `/faculty/film` → `/department/directing` → `/program/film-directing`.

Шлях підготовчого курсу:

`/` → `/courses` → `/course/cinema-start` → `#course-registration`.

Інші розділи: `/admissions`, `/matcher`, `/results`, `/events`, `/contacts`.
Усі інші сутності мають сторінки за власним `id` із файлу даних.

## Перевірки

- `npm run build` — успішна production-збірка; 49 статичних маршрутів, включно з іконкою.
- `npm run typecheck` — без помилок TypeScript.
- `npm test` — 10 успішних перевірок: 9 для каталогу та підбору, 1 для серверного HTML форм.

Перевірки фіксують пошук лише серед програм, які відповідають усім фільтрам.
Підбір перевіряє інтерес, заняття, рівень, форму, конкурс, межу ціни та порядок результатів.
CSS не приховує третю картку курсу на планшеті.
Візуальні знімки: [desktop 1440](demo/desktop.png), [mobile 390](demo/mobile.png), [tablet 768](demo/tablet.jpg).
Перевірка цих трьох ширин не виявила горизонтального прокручування.
Перевірки головної сторінки, форми та програми повернули `console-errors: 0`.
Темний режим перевірено після виправлення кольору кнопки мобільного меню.
Обидва основні шляхи показу пройдено кнопками та посиланнями браузера.
Перевірено зміну й скидання відповідей, порожній підбір, фільтри та перемикач рівня вступу.
Демо-реєстрація й форма запитання показують успішний локальний стан.
Модальні вікна закриваються клавішею Escape та переходом назад.
Серверний HTML обох форм має `enabled before hydration: 0`.

## Самостійні рішення та межі

- Збережено дизайн попереднього демо.
- Сторінки реалізовані React-компонентами; iframe та вставки HTML відсутні.
- Відповіді підбору живуть лише в пам’яті відкритої вкладки.
- Порожній результат залишається порожнім; застосунок не послаблює умови підбору.
- Форми використовують обов’язкові поля, перевірку email, телефону, віку та згоди.
- До підключення локальних обробників поля форм вимкнені через `fieldset disabled`.
- Після успішної перевірки форма очищає значення та показує фіксоване повідомлення.
- Дані форм не передаються мережею та не записуються до сховища браузера.
- Імена, ціни, дати, структури, контакти та адреса — тестові приклади.
- Відео замінено ілюстративними фото й описами робіт.
- Реальні правила вступу 2027, ціни та структуру треба підтвердити перед публікацією.
- Backend, база даних, CRM, пошта, оплата та реальна реєстрація не входять до демо.
